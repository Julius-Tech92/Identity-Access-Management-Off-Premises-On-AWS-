This project uses AWS to showcase Identity and Access Management (IAM) in a cloud context. It demonstrates how to apply least-privilege access, enforce authentication and authorization policies in AWS, and securely manage users, groups, roles, and permissions. The project showcases best practices for centralized identity management, cloud-based access control, and upholding security compliance in an on-demand, scalable setting.
